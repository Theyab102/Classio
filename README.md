# Classio

Classio is a React study workspace for organizing documents, taking notes, reviewing flashcards and building presentations. Classio is free for all users and the study workspace opens in guest mode after the 13+ check.

## Run locally

Use Node.js 22 or 24. Run `npm ci`, then `npm start` for the browser app. The guest workspace and policy pages work with the browser app alone. Use Vercel’s local development server to test the server-side AI endpoints with a configured provider. Copy the setting names you need from [.env.example](.env.example).

- `npm run build` builds the browser app into `build/`.
- `CI=true npm test -- --watchAll=false` runs the focused regression tests.
- `node --test server/*.test.js` checks guest AI, transcription and provider failover with mocked providers.
- `npm run test:browser` tests the production build with Playwright on desktop, phone and tablet widths in both themes. Install Chromium with `npx playwright install chromium` or set `CLASSIO_CHROMIUM_PATH`. The test uses explicit AI/speech fixtures, real PDF/PPTX uploads and playable WAV bytes; it does not test live provider access. Screenshots are written to a temporary folder, or `CLASSIO_BROWSER_OUTPUT`.
- `npm run check:ai` checks the local server configuration and prints missing setting names, never their values.
- The policy URLs are `/privacy`, `/terms` and `/copyright`.

## AI providers and Vercel settings

The browser always calls the same-origin `/api/study` endpoint. Groq remains the default provider. An optional Gemini adapter supports text, inline images, conversation history and short audio recordings; keys never enter the browser bundle. With both enabled, `AI_PROVIDER_ORDER=groq,gemini` uses Gemini after a Groq rate limit, network failure or service outage. One quota reservation covers the whole request. Content-policy blocks are not retried through another provider, and truncated answers are reported as incomplete.

The backend accepts the confirmed case-sensitive Vercel names **`Groq_Key`** and **`Gemini_Key`**, as well as canonical `GROQ_API_KEY` and `GEMINI_API_KEY`. A nonempty canonical setting takes precedence. Credentials are server-only. Do not create a `REACT_APP_` provider credential: the build script excludes legacy public provider/secret variables before invoking CRA. Remove obsolete exposed credentials from Vercel and revoke them at the provider. The owner confirmed the credentials exposed in the supplied screenshots were replaced; no exposed value is included in this repository.

Groq is enabled by a valid non-placeholder key. Optional Gemini settings include `GEMINI_ENABLED=true` and `GEMINI_MODEL`. Key presence alone does not enable Gemini. Without model overrides, the server discovers a supported model from the actual provider model list and caches that list briefly. Text and image tasks select compatible models; missing vision access produces a specific error. Explicit overrides are `GROQ_TEXT_MODEL`, `GROQ_VISION_MODEL` and `GEMINI_MODEL`. This integration does not provision keys, provider permissions or free-tier quotas. Invalid credentials and rate-limited providers enter a short cooldown per warm server instance instead of being repeatedly retried.

Quota mode defaults to **`instance`** when no Firebase service account is configured. It stores bounded, short-lived counters in the warm function's memory: 18 study requests per client per ten minutes, 250 per instance per day; transcription has separate lower limits. These counters reset on cold starts and are **not a deployment-wide hard budget**. Set provider-side spend limits. For shared transactional quotas, set `AI_QUOTA_MODE=firestore`, a valid `FIREBASE_SERVICE_ACCOUNT_JSON`, and a random `AI_RATE_LIMIT_SECRET` of at least 32 characters. Shared mode is also selected automatically if the service account setting exists; incomplete shared configuration fails closed. Enable Firestore TTL on `aiRateLimits.expiresAt` in that mode. A shared quota lookup failure never silently changes to an instance quota.

**Audience:** Classio stays free and 13+. Keep Gemini disabled unless your selected Google product's terms or authorization permit this app and audience. The existing launch guidance flags the Gemini Developer API's restriction concerning apps likely to be used by under-18s. Review the current terms before enabling it; a backend flag is not age verification. Groq remains available independently. Unconfigured AI returns a specific error inside the study tools and never prevents entering the guest workspace.

The API reserves quota before calling either provider, bounds model discovery at five seconds and generation at eighteen seconds per provider, and bounds shared quota lookup at eight seconds. `vercel.json` assigns the study function a 60-second budget. Diagnostic logs include provider/error codes rather than prompts or credentials.

If a deployed study tool says AI is unavailable, open `/api/status` on that deployment. It reports missing or malformed setting names and enabled providers without returning credentials. This checks configuration only, not provider authorization, quota availability or Firestore permissions. Add the missing settings securely in the Classio Vercel project's **Production** environment, redeploy, then test an actual guest request from the site. A GitHub push deploys code; it does not create provider credentials or change Vercel's environment settings.

## Appearance and devices

The welcome page follows the device color scheme by default. Its Appearance selector offers Light, Dark and Use device setting; an explicit selection is remembered across visits. Eligibility and terms acknowledgment are also remembered in the same browser without retaining the date of birth. Guests still start a fresh workspace when the session ends.

The Library restores the original **Blank document, Upload document, Record audio and Website link** actions. **Create new** also contains AI notes, a course and folder creation. Search, type filters, sorting and recent materials use real user content. Phones use a hamburger menu containing every study tool. Tablet and PC sidebars scroll, including account and appearance controls. **AI Assistant** in navigation and visible page composers open the same conversation. The assistant reserves space on larger desktops and becomes a dismissible drawer on smaller screens. It sends only the current material, the current study activity, conversation and user attachments; Library context includes titles and folder names, not every document's contents. A failed workspace download offers a reload action with an explanation that reloading ends guest work.

Character customization keeps Face, Hair, Outfit and Details, with original SVG previews, live staged changes, color choices, Randomize and Reset look. Save changes commits the character; Cancel leaves the previous character intact. Profile and sidebar use the same renderer and saved character.

## Before public launch

1. **Domain and sign-in.** Connect the chosen domain to the existing Vercel project, verify DNS and HTTPS, and add the hostname to Firebase Authentication’s authorized domains. Test Google sign-in and direct navigation to all three policy pages on that domain. The favicon uses the existing Classio logo. [Vercel domain setup](https://vercel.com/docs/domains/set-up-custom-domain)
2. **Operator and privacy notice.** Configure the legal operator name and a monitored privacy address. Confirm the live data flows, retention and deletion process, provider settings and any required privacy disclosures for the markets you serve. The policy copy is a draft until those details are verified. Check the deployed site, Vercel integrations and Google tag settings for any analytics, advertising or replay code added outside this repository. [UAE data protection laws](https://u.ae/en/about-the-uae/digital-uae/data/data-protection-laws)
3. **Age and cloud permissions.** The neutral date-of-birth check runs before Firebase loads. The date stays in memory and only the decision and terms step are kept in this browser. Ineligible decisions expire after one day so eligibility can be checked again. This is a self-declared age screen. Review whether the service is directed at children and how reports of under-13 accounts will be handled. Verify Firebase access against your actual project. [firestore.rules](firestore.rules) is an owner-only baseline for personal folders and notes. It denies client access to other collections, including legacy group data and AI rate counters. Review and test it in staging before applying it to an existing project. Also check any live Storage and Realtime Database rules. [FTC COPPA guidance](https://www.ftc.gov/business-guidance/resources/complying-coppa-frequently-asked-questions)
4. **AI credentials and limits.** Configure a server-only provider key and the quota mode described above. Rotate keys previously exposed in screenshots or browser builds. Test guest text, images and audio from the production origin. Guest and signed-in requests use the same limits. Counters use short-lived HMACs of IP addresses; instance mode is not a shared hard spending cap. Verify provider retention and settings. Review Groq’s conditions for serving minors. The Gemini Developer API terms exclude applications likely to be used by under-18s. [Groq Services Agreement](https://console.groq.com/docs/legal/services-agreement) · [Gemini API terms](https://ai.google.dev/gemini-api/terms)
5. **Copyright.** Set a monitored reporting address and decide how reports, counter-notices and repeat infringement will be handled. If you seek U.S. DMCA safe-harbor protection for hosted user content, complete the Copyright Office registration, publish the designated agent’s name, mailing address, phone and email on the copyright page, and maintain the designation and process. [U.S. Copyright Office Section 512 guidance](https://www.copyright.gov/512/)
6. **Marketing email.** If you send marketing email, include a working unsubscribe link, required sender information and postal address, and maintain a suppression list. [FTC CAN-SPAM guide](https://www.ftc.gov/business-guidance/resources/can-spam-act-compliance-guide-business)

## Workspace behavior

Signed-in users keep an account-specific cached folder list. Cloud records are restored through the same Firebase account. The previous unscoped `classio_v2` entry stays in browser storage because it has no account identifier. If that entry contains the only copy of old offline work, recover it in the original browser before clearing site data. Original personal files are still stored separately in that browser. Guests can use all the study tools and download results. Their workspace clears on refresh or when the tab closes. The Library’s optional sign-in button imports the guest workspace into the signed-in account. Notes, progress and supported file metadata sync to Firebase. Original uploads remain on the device where they were added.

The built app serves DM Sans, Fraunces and KaTeX fonts from its own assets. Website notes use `/api/source` to read a public page with its actual tables and figures. The reader checks public DNS addresses, pins the connection and validates redirects. Source figures retain credits; blocked or sign-in-only pages offer manual text entry.

Signed-in assistant history has an account-specific browser cache and an owner-only cloud preference document at `users/{uid}/preferences/assistant`. Deploy the updated [Firestore rules](firestore.rules) to enable that cloud path, after reviewing them against existing project collections. If cloud saving fails, the panel reports that history is saved in this browser only. Guests keep history in memory for the current session. Attachment image bytes are not saved in conversation history. Nested presentation tables are encoded losslessly for Firestore and decoded on restore; legacy documents remain supported.

## Study tools

- **Notes** combines writing, AI note generation and lessons in one workspace. Its compact toolbar supports fonts, sizes, headings, lists, editable tables, images and KaTeX equations. HTML downloads include native MathML for equations. Generate notes inserts the formatted result directly into the editor. Existing writing is preserved by appending; explicit Organize can replace unchanged writing, and generation can be undone. The image picker searches Wikimedia Commons and shows image credits. Generation, equations, images and saved versions open in dismissible dialogs. Notes save automatically to workspace state; named versions and HTML downloads remain available from Note options.
- **Document viewers** render original PDF pages locally and keep their proportions and scale during page navigation. PDF text search highlights supported text. PPTX search finds parsed native slide text; the viewer supports native text, images and tables. Both viewers retain zoom, page position and page-specific pen/highlighter strokes. Complex PowerPoint effects are limited by the existing native renderer; the original file is downloadable.
- **Presentations** preview the same generated deck in two or three layouts before applying one. Edit text, tables and images, annotate slides and export as PDF or PPTX.
- **Guided lessons with questions**, selected from the Notes mode menu, turns a topic, document or note into structured explanations, worked examples and knowledge checks. The outline, progress, answers and active lesson are saved. Browser read-aloud appears where supported. Lesson explanations can be added to notes without losing existing writing.
- **Quizzes** generates validated questions from the selected material, with difficulty/count settings, hints, checked answers, explanations and results. Attempts and progress stay with the file.
- **Flashcards** provides animated question/answer cards, editing, search, category filters, spaced review, study shortcuts and TSV downloads. Generated cards append by default. Replacing cards or deleting one requires confirmation. Missed cards are due again in ten minutes; successful reviews use gradually longer intervals. Existing study games remain accessible separately.
- **Record audio** can turn uploaded recordings up to 2.8 MB into a transcript and notes. It can also use compatible browsers for live dictation. Keep the original file if an upload exceeds the limit or transcription is unavailable.
- **Podcasts** creates a grounded two-host script and requests real speech audio for each turn from the existing `Theyab102/classio-tts` Hugging Face Space. The browser combines the actual decoded audio into a playable WAV. Controls use real media duration and support play/pause, seek, speed, volume, timed sections, transcript speakers and saved playback position. Transcripts and episode history remain available if speech generation fails; a player is shown only when audio exists. Speaker labels remain in the transcript and are removed before speech synthesis, including when rebuilding older audio. “Ask the hosts aloud” pauses the episode, records a question, transcribes it through `/api/study`, generates a section-grounded reply and plays a real spoken answer before resuming. Typing is available as a fallback. This is a recorded question-and-answer flow; it requires microphone permission, transcription and the speech service. Voice discovery reports when only one service voice is available. Binary audio stays on the creating device (temporary memory for guests, IndexedDB when signed in); metadata/transcripts sync with the file. Set `REACT_APP_CLASSIO_TTS_URL` to an empty value at build time to disable the speech integration. Live speech service availability must be tested after the Space wakes. [Classio TTS Space](https://huggingface.co/spaces/Theyab102/classio-tts)
- **Video links** first try `/api/transcript`, which retrieves actual available YouTube captions with bounded requests and allowlisted hosts. Existing transcript fallbacks and manual transcript entry remain. Missing captions never turn into invented title-based notes.

Equations use a shared Markdown/LaTeX renderer across notes, guided lessons, quizzes, flashcards, link notes and the assistant. It preserves backslash and dollar delimiters before Markdown parsing, renders fractions, roots, units and subscripts with KaTeX, and recovers supported notation in older saved content. Code examples stay code. Headings, emphasis and GFM tables render as rich content.

The assistant lives in a collapsible right-side panel with an Ask Classio button when minimized. The original bundled `ClassioLogo.png` is used for the brand and app icons. Character previews now render original Three.js meshes with lighting and shadows, full-body rotation and the existing customization fields. Static renders provide a fallback on devices without WebGL2; no third-party character assets are used.
